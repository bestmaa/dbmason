# Support

DBMason is a community open-source project.

- Use [GitHub Discussions](https://github.com/bestmaa/dbmason/discussions) for
  setup questions, design ideas, and usage help.
- Use the issue templates for reproducible bugs and scoped feature proposals.
- Use [private vulnerability reporting](https://github.com/bestmaa/dbmason/security/advisories/new)
  for security issues. Never post credentials or an exploit publicly.

Please include the DBMason version, database engine and version, deployment
method, sanitized logs, and the smallest reproduction you can provide. Remove
passwords, connection URLs, tokens, personal data, query results, and private
hostnames before sharing diagnostics.
